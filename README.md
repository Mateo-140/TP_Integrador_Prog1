# Gestión de Datos de Países en Python

Este proyecto es el **Trabajo Práctico Integrador (TPI)** para la materia **Programación 1** de la *Tecnicatura Universitaria en Programación a Distancia (UTN)*. Consiste en una aplicación de consola desarrollada en Python 3.x que permite administrar, filtrar, ordenar y calcular estadísticas sobre un dataset de países almacenado en formato CSV.

## 📋 Características Principales
El sistema ofrece un menú interactivo en consola con las siguientes funcionalidades mínimas:
* **Gestión de datos:** Agregar nuevos países (sin campos vacíos) y actualizar población/superficie de registros existentes.
* **Búsquedas y Filtros:** Búsqueda por coincidencia parcial o exacta por nombre, y filtrado avanzado por continente, rango de población o rango de superficie.
* **Ordenamiento:** Clasificación de países por nombre, población o superficie de manera ascendente o descendente.
* **Estadísticas Automáticas:** Cálculo de países con mayor/menor población, promedios generales y conteo de países por continente.
* **Robustez:** Control de errores de formato en el CSV y validación de entradas de usuario para evitar fallos del sistema.
